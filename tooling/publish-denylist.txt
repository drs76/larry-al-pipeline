# Publish gate — patterns that MUST NOT reach the public repo.
#
# One extended-regex (PCRE) per line. Blank lines and # comments ignored. A match
# anywhere in the exported tree ABORTS the publish. This file is the durable record of
# the pre-publication scrub; without it the rules live only in someone's memory and the
# next sync silently re-exports what an earlier one removed.
#
# Adding an exception: prefer fixing the file. If a hit is genuinely intended (raw
# captured evidence, for example), narrow the pattern and say why on the line above,
# so the reason survives the person who knew it.

# A SESSION_SECRET and POSTGRES_PASSWORD were found in
# archive/librechat/docker-compose.yml on 2026-09-10, AFTER the repo had been public
# for some hours. The directory was deleted rather than redacted (LibreChat was
# retired; nothing listened behind it). Both values are burned.
#
# This matches the SHAPE, not the values. Listing the literals here would put the
# secrets into the very file that exists to keep them out — and this file is itself
# published, so the denylist would have leaked what it guards.
(SESSION_SECRET|POSTGRES_PASSWORD)\s*[:=]\s*[0-9a-f]{16,}
